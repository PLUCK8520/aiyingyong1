# 内部竞争格局评估（知识库 Agent 平台）

沿用三类玩家划分，但补上内部评估结论：

- **云厂商系**：托管知识库 + 模型 + 编排一体化。优势是弹性与生态，劣势是**数据边界**敏感客户
  不愿把知识资产放到公有云，金融政企单子常被卡在合规环节。
- **独立 AI 创业公司**：检索与 Agent 编排深度最好，POC 演示效果领先。劣势是交付与合规资质，
  金融客户招标时"没有等保与行业案例"直接出局。
- **传统内容管理软件商转型**：存量客户与私有化交付能力是护城河，模型能力是短板，
  常见做法是外采模型 + 自研检索层。

内部结论：**金融与制造业是三类玩家重叠最激烈的战场**；制造业客户更看重解析非结构化工艺文件
的能力，这一点常被低估。

补充口径：本清单用于内部**竞品**盘点，按**厂商分类**给出三类玩家的**差异化优势**对比，
不包含任何对外报价信息。
