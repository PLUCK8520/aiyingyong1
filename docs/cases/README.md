## 四条跨案例的通则

1. **失败被伪装成"正确行为"是最危险的一类**（#14 的拒编页、#15 的"0 条问题"）。
   排查时永远追问：这个正确结果真的走了预期路径吗？
2. **跨模块的字符串/格式契约必须单点收敛**（#14 的编号规范化、#16 的编号拼装）。
   生成方和消费方各写一套解析，迟早漂移。
3. **计数为 0、空列表这类状态天生有歧义**——必须用显式字段命名"无对象/无结论"（#15），
   不能让读者从一串 0 里猜。
4. **凡"默认值"，先问它落在安全侧还是危险侧**（#17）。涉及花钱 / 删数据 / 联网的开关，
   默认必须是"不做"那一侧；文档串与默认值要对读——它们不一致时，没有任何机制会通知你。
